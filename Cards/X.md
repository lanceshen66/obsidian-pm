2026 X 创作者收益完整指南：资格、申请、认证、提现、税务与封号红线

更新时间：2026 年 10 月 10 日

最近很多人在问：

X 到底满足什么条件才能开通创作者收益？ 50 万还是 500 万曝光？ 普通浏览量算不算？ 中国大陆能不能申请？ 身份证、护照怎么认证？ Stripe 怎么绑定？ 多久发一次钱？ 要不要交税？ 哪些操作最容易被取消收益甚至封号？

我查阅了 X Help Center、X 官方计划条款、创作者变现政策、身份认证政策以及 Stripe 官方资料，整理成这一篇。

先说最重要的一件事：

## 

一、以前的“500 万曝光规则”已经过时

X 原来的 Creator Revenue Sharing（创作者收益分享） 已经停止。

- 2026 年 8 月 7 日：停止接受新用户申请
    
- 2026 年 9 月 7 日：旧计划正式结束
    
- 2026 年 9 月 8 日起：逐步转向新的 Original Content Rewards（原创内容奖励计划）
    

所以现在网上仍然大量流传的：

> Premium + 500 个认证粉丝 + 过去 3 个月 500 万曝光

属于旧版 Creator Revenue Sharing 的规则，不能再直接拿来判断现在是否具备申请资格。

# 

二、现在申请创作者收益，需要满足什么条件？

按照 X 当前 Original Content Rewards 官方页面，申请时需要同时满足以下核心条件：

1. 年满 18 周岁

必须满 18 岁。

2. 所在国家或地区受到支持

必须实际位于 X Original Content Rewards 支持的国家或地区。

3. 账号状态正常

账号必须保持良好状态，不能存在反复违反：

- X 用户协议
    
- 创作者变现政策
    
- X 平台规则
    

等记录。

4. 账号类型符合要求

可以是：

- Personal Account
    
- Business Account
    

政治组织、政府组织等账号不符合该计划资格。

5. 必须订阅符合条件的 Premium

目前明确支持：

- X Premium
    
- X Premium+
    
- Premium Business
    

Premium Basic 不属于申请该计划所要求的 Premium 档位。

但是注意：Premium Basic 用户给你产生的符合条件曝光，官方又明确可以进入“Qualified Impressions”的范围。

这两个概念不要混淆。

6. 最近 90 天至少达到 50 万次指定曝光

这是现在最容易被理解错的一条。

官方要求的是：

过去 90 天至少获得 500,000 次来自认证用户、发生在 Home Timeline 的曝光。

不是简单地看 Analytics 里的总 Impressions。

而且：

Reply 帖子的曝光不计入这项申请门槛。

7. 至少 500 个认证粉丝

官方原文要求：

500 verified followers

也就是说，不是单纯拥有 500 个普通粉丝。

8. 持续发布原创内容

账号需要积极发布符合 Original Content Rewards 定义的原创内容。

即使其他数字全部达标，如果账号主要依靠搬运、简单改写、转载、聚合内容，也可能无法通过审核。

而且必须注意：

满足以上条件 ≠ 一定批准。

X 明确写明，达到门槛后只是获得“提交申请”的资格，平台仍然会审核是否接受你加入。

# 

三、除了上面的数字，还有一层“通用变现资格”

X 的 Creator Monetization Standards 对所有参与变现的创作者还有一套基础要求。

包括：

- 至少 18 岁
    
- 居住在支持变现的国家或地区
    
- X 账号至少活跃 3 个月
    
- 账号资料完整
    
- 设置账号名称
    
- 有 Bio
    
- 有头像
    
- 有 Header 图片
    
- 邮箱已经验证
    
- 开启两步验证（2FA）
    
- 账号状态良好
    
- 不能反复违反 X 用户协议或变现政策
    
- 完成身份认证
    
- 建立有效的收款账户
    

因此，不建议只盯着“50 万曝光 + 500 认证粉丝”两个数字。

真正审核的是账号整体是否符合变现条件。

# 

四、这 50 万曝光到底怎么算？

这是整个新计划最重要的部分。

X 将真正能够进入收益计算的曝光称为：

Qualified Impressions（合格曝光）

目前官方定义大致可以理解为：

> Premium 用户在 Home Timeline 中看到你的原创内容，并且帖子至少有 50% 出现在用户屏幕中。

产生曝光的用户可以来自：

- Premium Basic
    
- Premium
    
- Premium+
    
- Premium Business
    

但以下曝光会被排除：

- 同一个账号对同一帖子重复产生的曝光
    
- 付费推广产生的曝光
    
- 人工制造的曝光
    
- 欺诈性曝光
    

因此：

100 万普通总曝光，并不代表有 100 万收益曝光。

而申请资格要求的 50 万，也是特定的 Home Timeline 认证用户曝光，而不是简单看后台总流量。

# 

五、Reply 的流量算不算？

这里需要分开看。

申请 Original Content Rewards 时，官方已经明确：

回复帖（Replies）的曝光不计入申请所需的 50 万 Home Timeline 曝光。

所以以前大量依靠疯狂回复别人帖子来“刷有效流量”的玩法，在新制度下面价值已经明显不同。

对于想开通收益的人来说，核心已经更加偏向：

自己的原创主帖。

尤其是能够进入 Home Timeline 推荐流的原创内容。

# 

六、什么才算“原创内容”？

X 对这一点写得非常详细。

允许的原创不仅包括完全自己拍摄、自己写出来的内容。

以下同样可以属于原创：

- 自己写的观点
    
- 原创文章
    
- 原创图片
    
- 原创视频
    
- 专业知识分享
    
- 新闻评论
    
- 对热点进行分析
    
- 对事件增加自己的背景信息
    
- 对其他内容进行有实质价值的解读
    

所以“评论别人发生的事情”本身并不会失去原创资格。

关键是：

你有没有提供实质性的个人观点、分析、知识或新的价值。

反过来，以下通常不会被认为是符合该计划要求的原创：

- 整段复制别人文字
    
- 下载别人图片重新上传
    
- 下载别人视频重新上传
    
- 只改几个字
    
- 视频只改速度
    
- 只套滤镜
    
- 只增加字幕
    
- 大量拼接别人内容而没有实质分析
    
- 从其他平台搬运他人的作品
    

简单理解：

换几个字 ≠ 原创。 加个字幕 ≠ 原创。 重新上传 ≠ 原创。 真正增加自己的观点和价值，才是关键。

# 

七、有一个很多人不知道的特殊规则

X 当前政策中还有一条非常值得做收益账号的人注意：

以下内容可能直接被排除在 Original Content Rewards 收益之外：

专门围绕“如何变现、如何提高收益、如何最大化收益”等主题制作的内容。

官方原文明确列出了：

- monetization coaching
    
- monetization discussion
    
- maximizing payouts
    

如果内容“ exclusively focused ”于这些主题，就可能不具备奖励资格。

所以像本文这种“X 创作者收益教程”当然可以正常发布、交流、涨粉，但不要默认它本身一定属于能够产生 Original Content Rewards 的奖励内容。

# 

八、满足条件以后在哪里申请？

目前官方入口是：

Creator Studio → Original Content Rewards

系统会显示你的资格状态。

满足所有条件后，可以直接提交申请。

基本流程是：

达到资格 → Creator Studio → Original Content Rewards → 提交申请 → X 审核 → 审核通过 → 完成收款及身份认证 → 开始参与收益

官方明确表示：

达到要求后可以提交一个简短申请，然后由 X 进行审核并通知结果。

# 

九、申请被拒绝怎么办？

现在官方给出了比较明确的规则。

第一次申请没有通过：

可以提交一次 Appeal（申诉）。

如果申诉仍然失败：

42 天以后可以重新申请。

前提是重新申请时仍然满足所有资格要求。

# 

十、通过以后还需要准备什么？

通过申请并不意味着钱马上能够打到银行卡。

还需要完成支付账户和 KYC 身份认证。

目前分成两种情况。

## 

美国用户

当前官方规则是：

通过 X Money 接收 Original Content Rewards。

X Money 与一个人的身份绑定。

官方还特别说明：

- 一个 X Money 只能连接一个 X 账号
    
- 一个人不能创建多个 X Money 账户
    
- X Money 账户与 SSN 等身份信息相关
    

同时 X Money 当前仍处于美国用户逐步开放阶段，并非全球通用。

## 

非美国用户

目前主要通过：

Stripe

需要：

1. 建立 Stripe payout account
    
2. 完成 Stripe 身份认证
    
3. 提交支付信息
    
4. 提交必要的税务信息
    

然后才能正常收到收益。

# 

十一、身份认证到底需要什么材料？

这一部分不要相信“只需要一张身份证”之类绝对说法。

因为 Stripe 官方明确说明：

实际认证要求根据国家、账号类型以及自动验证结果不同而变化。

一般可能涉及：

身份信息

- 法定姓名
    
- 出生日期
    
- 居住地址
    
- 国家/地区
    
- 政府签发的有效带照片证件
    

常见证件可能包括：

- 护照
    
- 驾驶执照
    
- 当地身份证件
    

具体接受哪一种，以 Stripe 对相应国家显示的证件列表为准。

如果系统无法自动确认身份，还可能要求：

- 重新拍摄证件
    
- 自拍或人脸认证
    
- 地址证明
    

Stripe 明确要求身份证明：

- 必须有效、未过期
    
- 必须清晰
    
- 通常要求彩色
    
- 身份证/驾照可能要求正反面
    
- 护照需要完整个人信息页
    
- 信息必须与 Stripe 账户中的资料一致
    

部分地区在无法自动验证住址时，还可能需要最近数月内的有效地址证明。

# 

十二、最重要的一点：身份、地址和收款信息必须真实一致

X 的计划条款明确要求：

提供给 X 和支付处理商的信息必须真实、准确、完整并保持最新。

支付处理商还可以要求：

- 身份证明
    
- 居住证明
    
- 收款资料
    
- 税务资料
    

因此不要把：

“换 IP”

“改 X 地区”

“填一个海外地址”

误认为等于获得该国家的收款资格。

真正到了 KYC 和支付阶段，支付平台可能核验：

人是谁、住在哪里、税务身份是什么、银行账户属于谁。

如果存在身份虚假、地址虚假或者其他重大信息不一致，可能导致无法加入计划、暂停付款、取消收益资格，严重情况下还可能涉及账号处罚。

# 

十三、中国大陆目前支持吗？

按照 X 官方截至本文更新时公布的 Original Content Rewards 国家/地区名单：

中国大陆目前没有出现在支持名单中。

官方名单中明确存在：

- 中国香港：支持
    
- 中国台湾：支持
    

目前名单中没有：

- 中国大陆
    
- 中国澳门
    

因此“中国用户可以使用 X”与“中国大陆居民一定可以直接完成创作者收益收款”是两件不同的事情。

最终应以 Creator Studio 中的实际资格、真实居住地以及支付平台 KYC 结果为准。

# 

十五、X 到底怎么计算你能赚多少钱？

这可能是目前最没有“固定答案”的部分。

X 只明确说明：

收益与 Premium 用户对原创内容产生的符合条件曝光有关。

但截至目前，X 并没有公开一个可以简单计算的固定公式，例如：

> 100 万曝光 = 多少美元

也没有公布一个长期固定 CPM。

而且计划条款明确保留了修改收益计算结构的权利。

所以网上出现的：

“100 万曝光固定多少美元”

“一个蓝 V 曝光固定多少钱”

这类说法最多只能代表个别创作者某一期的实际数据，不能当成 X 官方固定结算标准。

同时，付费推广产生的曝光、作弊流量和被判定为人为制造的浏览量都可能被排除。

# 

十六、收益多久发一次？

目前官方规则是：

每两周处理一次付款。

最低付款门槛：

30 美元。

也就是说，累计收益没有达到 30 美元时，不会进入正常付款。

需要特别注意：

“每两周处理一次”并不代表官方承诺某一天一定到账银行卡。

支付处理时间、银行处理时间、身份审核、税务审核等，都可能影响最终到账时间。

而且 X 的计划条款保留调整付款周期的权利。

# 

十七、Stripe 或支付平台会不会扣手续费？

有可能。

Original Content Rewards 条款明确写明：

实际支付金额可以扣除 Payment Processor 的处理费用后再支付。

因此后台显示的收益和最终进入银行账户的净额之间，理论上可能存在支付处理费用、汇兑等差异。

具体费用仍取决于相应支付处理方式和地区。

# 

十八、创作者收益到底要不要交税？

要把两个概念区分开。

第一层：X 会不会统一扣固定税率？

目前没有一个适用于全球所有创作者的统一“X 创作者税率”。

第二层：收益本身是否属于应税收入？

X 的计划条款明确写明：

创作者本人负责其收益所产生的适用税款。

而且如果法律要求 X 扣缴某些税费：

X 有权直接从应付款中扣除或代扣。

因此并不能理解成：

“X 打给我的钱都是税后收入，以后什么都不用管。”

实际税务责任取决于：

- 税务居民身份
    
- 居住国家或地区
    
- 个人还是企业
    
- 收入性质
    
- 当地税法
    
- 是否存在预扣税义务
    

非美国用户通过 Stripe 时，还可能被要求填写税务身份资料。

Stripe Express 支持 W-8/W-9 等税务状态确认流程，但具体要求以 X/Stripe 在你的账户中实际提出的要求为准。

不能简单地说所有海外创作者统一填某一种税表。

# 

十九、什么行为最容易把收益资格做没？

这一部分比冲曝光更加重要。

新 Original Content Rewards 对账号质量的要求明显提高。

以下操作风险尤其高。

1. 刷浏览量

包括：

- Bot
    
- 自动化刷量
    
- 人工制造大量虚假曝光
    
- 其他人为操纵算法或浏览量的方法
    

一旦认定人为抬高浏览量：

X 可以取消应付收益，并直接终止计划资格。

2. 刷赞、刷粉、刷回复

官方明确禁止利用自动化工具、机器人或软件人为制造：

- Like
    
- Follow
    
- View
    
- Comment
    
- Share
    

3. 高频诱导互动

这一条很多运营账号非常容易踩。

Original Content Rewards 明确规定不能反复要求用户：

- 点赞
    
- 回复
    
- 收藏
    
- 关注
    
- 转发
    

官方称之为：

Solicit engagements

这与偶尔自然地邀请讨论不是完全同一个概念。

真正危险的是账号长期、大量、重复把“点赞、关注、回复、转发”本身作为内容核心。

4. 大量搬运

完整搬运、简单修改、重新上传别人内容，很可能不能获得 Original Content Rewards。

5. 自动生成、自动发布内容

官方明确列出：

通过 automated means 创建或发布的内容可能不具备奖励资格。

但这里也不要反向扩大解释成：

“所有使用 AI 辅助写作的内容一律违规。”

X 当前公开规则并没有这样写。

6. 虚假或误导信息

Disinformation 或 misleading content 都可能失去收益资格。

7. Helpful Community Note

这是一个非常特殊的规则：

如果某条内容被添加了 Helpful Community Note，官方明确将它列为不能获得该计划奖励的内容之一。

8. 色情、明显不适宜或潜在有害内容

这些内容可能被限制变现或取消奖励资格。

9. 侵犯版权

即使内容形式上看起来经过处理，只要没有必要的版权、授权或者许可，仍然可能违反 X 的知识产权政策。

10. 专门研究“怎么薅 X 收益”

如果一个账号大量发布：

- 如何赚更多 X 收益
    
- 如何最大化付款
    
- 如何刷收益指标
    

也需要非常谨慎。

因为 X 已经明确把 exclusively focused on monetization coaching / discussion / maximizing payouts 的内容列入不具备奖励资格的范围。

# 

二十、违规以后只是“不赚钱”，还是会封号？

两者都有可能。

按照 X Creator Monetization Standards，处罚会根据严重程度、具体情形和历史违规记录决定。

可能包括：

降低推荐 → 内容不再大量推荐给未关注你的人

暂停收益 → 暂时不能参与部分或全部变现计划

永久取消收益资格 → 永久失去部分或全部变现功能

删除内容 → 删除或者要求删除违规帖子

暂停账号

甚至：

永久取消 X 账号使用资格。

所以需要特别区分：

“取消创作者收益资格”

和

“整个 X 账号被封”

并不是同一件事，但严重违规确实可能最终发展到账号级处罚。

# 

二十一、一个非常具体的 AI 违规案例

X 当前还有一条特殊政策：

自 2026 年 3 月 3 日起，如果发布 AI 生成的武装冲突视频，却没有明确披露这是 AI 生成内容：

第一次可能被暂停 Original Content Rewards 90 天。

后续再次违规：

可能被永久停止后续付款。

这条规则非常具体，也说明未来 X 对 AI 内容的变现监管很可能会越来越严格。

# 

二十二、已经进入计划后，流量掉下来会不会马上被踢出去？

按照目前 Original Content Rewards 条款：

账号加入以后，如果之后曝光跌破申请时的门槛，并不意味着因为这一点立即自动被移出计划。

但是：

- Premium 必须继续有效
    
- 必须持续发布原创内容
    
- 必须保持账号状态良好
    
- 不能操纵平台
    
- 不能作弊
    
- 必须持续满足相关变现政策
    

X 会定期重新审查参与计划的账号。

# 

二十三、最简单的申请路线图

如果想做 X 创作者收益，可以把整个流程记成：

第一步： 开通符合条件的 Premium。

第二步： 完善账号、验证邮箱、开启 2FA，并长期保持账号正常。

第三步： 持续做原创主帖，而不是把所有精力放在 Replies。

第四步： 过去 90 天获得至少 50 万次来自认证用户的 Home Timeline 曝光。

第五步： 拥有至少 500 个认证粉丝。

第六步： 进入 Creator Studio → Original Content Rewards。

第七步： 提交申请等待 X 审核。

第八步： 通过后完成真实身份认证。

美国用户走 X Money；非美国用户目前主要走 Stripe。

第九步： 填写支付及税务资料。

第十步： 累计达到最低 30 美元付款门槛后，按照当前约每两周一次的付款周期结算。

# 

二十四、最后总结

现在 X 创作者收益已经不是单纯的：

“发得多 + 回复多 + 总曝光高 = 能赚钱”。

新的 Original Content Rewards 明显在往另一套逻辑走：

**原创内容

- Home Timeline 推荐
    
- Premium 用户曝光
    
- 真实用户互动
    
- 身份真实性
    
- 长期账号质量**
    

所以如果真的准备长期做创作者，最重要的已经不是想办法“刷到一个数字”。

而是：

让更多真实的 Premium 用户，在 Home Timeline 看到你真正原创、有价值的内容。

这可能才是目前 X 最希望奖励的创作者。
